Install WheelMaker

Deploy WheelMaker and the built-in Gateway independently. Run either command from any directory.

AI deployment guide 中文部署指南

Deploy WheelMaker

Windows PowerShell

$ErrorActionPreference='Stop'; $d=Join-Path $HOME '.wheelmaker'; New-Item -ItemType Directory -Force -Path $d | Out-Null; $m=Join-Path $d 'deploy.mjs'; Invoke-WebRequest 'https://release.wheelmaker.top/deploy.mjs' -OutFile $m; & node $m

macOS / Linux

(d="$HOME/.wheelmaker" && mkdir -p "$d" && curl --fail --location --progress-bar --proto '=https' --tlsv1.2 'https://release.wheelmaker.top/deploy.mjs' --output "$d/deploy.mjs" && node "$d/deploy.mjs")

Deploy built-in Gateway

Windows PowerShell

$ErrorActionPreference='Stop'; $d=Join-Path $HOME '.wheelmaker'; New-Item -ItemType Directory -Force -Path $d | Out-Null; $m=Join-Path $d 'deploy.mjs'; Invoke-WebRequest 'https://release.wheelmaker.top/deploy.mjs' -OutFile $m; & node $m gateway

macOS / Linux

(d="$HOME/.wheelmaker" && mkdir -p "$d" && curl --fail --location --progress-bar --proto '=https' --tlsv1.2 'https://release.wheelmaker.top/deploy.mjs' --output "$d/deploy.mjs" && node "$d/deploy.mjs" gateway)

Requires Node.js. The default entrypoint is the built-in Gateway; choose Nginx separately only when you explicitly do not want Gateway.

Windows Desktop

Download the EXE directly, or install/update the standard WheelMaker and Desktop setup with shortcuts.

Download EXE

$ErrorActionPreference='Stop'; $d=Join-Path $HOME '.wheelmaker'; New-Item -ItemType Directory -Force -Path $d | Out-Null; $m=Join-Path $d 'deploy.mjs'; if (!(Test-Path -LiteralPath $m)) { Invoke-WebRequest 'https://release.wheelmaker.top/deploy.mjs' -OutFile $m }; & node $m; & node $m desktop-update; $e=Join-Path $d 'desktop\WheelMakerDesktop.exe'; $w=New-Object -ComObject WScript.Shell; $desktopLink=Join-Path ([Environment]::GetFolderPath('Desktop')) 'WheelMaker.lnk'; $programs=Join-Path ([Environment]::GetFolderPath('Programs')) 'WheelMaker'; New-Item -ItemType Directory -Force -Path $programs | Out-Null; $links=@($desktopLink,(Join-Path $programs 'WheelMaker.lnk')); foreach ($link in $links) { $s=$w.CreateShortcut($link); $s.TargetPath=$e; $s.WorkingDirectory=Split-Path -Parent $e; $s.IconLocation="$e,0"; $s.Save() }

Optional knowledge workflow

Build your own Personal Wiki

Personal Wiki Kit adds a private, Git-backed knowledge base that WheelMaker and other AI tools can query and update through reusable skills. WheelMaker does not store your articles.

  1. 01

    Install the public Kit

    Download and run setup-wiki.bat. It selects the stable Windows Kit, verifies its size and SHA-256, then creates a separate private Git repository and local user configuration. The new repository already contains open-wiki.bat, publish-wiki.bat, and update-wiki-kit.bat.

    Download setup-wiki.bat 阅读中文完整部署指南
  2. 02

    Map your projects

    Edit ~/.personal-wiki/project-routing.json to map local source folders to Wiki project IDs. Multiple local projects can share the same Wiki project ID. To show the WheelMaker header shortcut, set knowledgeRegistry.publicUrl on your WheelMaker server.

  3. 03

    Read, approve, publish

    Use open-wiki.bat for local reading. AI agents use the installed lookup and publishing skills; you approve knowledge changes before they are written. Run publish-wiki.bat when you are ready to publish.

Private by design. Articles and attachments stay in your private Git repository; machine-specific paths and project mappings stay under ~/.personal-wiki/. The public Kit contains only reusable code, templates, and skills—never your content, credentials, or server secrets.
