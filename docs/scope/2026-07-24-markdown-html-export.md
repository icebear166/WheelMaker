# Markdown HTML 导出

## 目标

让用户能够将项目 Markdown 文件或一次已完成的聊天回复导出成可独立使用的 HTML 网页。导出的页面必须离线可打开、保持 WheelMaker Markdown 预览的主要渲染效果，并在各端遵循已有截图功能的交付习惯：Desktop 交付可粘贴的文件，Android 交付可分享的文件，浏览器下载文件。

## 决策

- **导出对象**：支持项目中的 `.md` 文件与每个 `prompt_done` 对应的回复内容；其他文件类型不提供 HTML 导出。
- **文件入口**：当活动预览标签是已加载的 Markdown 文件时，在预览工作台的“更多操作”菜单显示“Export as HTML”；聊天 Markdown 文件链接的右键菜单也显示该动作。右键导出时，若文件尚未加载，先读取该文件再生成导出。
- **回复入口**：在 `prompt_done` 的复制和截图操作区新增“Export response HTML”动作；导出范围与现有回复复制/截图使用的 Markdown 内容范围一致。
- **网页形态**：每次导出生成单个完整 HTML 文档，包含自适应浅色/深色主题、Markdown 排版、GFM 元素、代码高亮和已渲染的安全 HTML。页面不依赖 WheelMaker、外部样式表或外部脚本才能显示核心内容。
- **图片策略**：项目内相对图片按当前 Markdown 文件所在目录解析，只允许读取项目根目录内的目标，并以内嵌数据形式写入导出页面。远程图片尽力抓取并内嵌；网络、跨域或解码失败时保留原 URL，导出仍成功并向用户说明有未内嵌资源。
- **安全 HTML**：Markdown 内的原始 HTML 允许参与渲染，但必须经白名单清理；脚本、事件属性、危险 URL、嵌入式可执行内容和其他不安全标记不得进入导出页面。
- **命名**：文件导出使用原文件名替换扩展名，例如 `README.md` 导出为 `README.html`；回复导出使用 `wheelmaker-response-turn-<序号>-<ISO 时间>.html`。
- **Desktop 输出**：将生成的 HTML 写入受控临时文件，再通过 Desktop 原生桥接把该文件放进系统剪贴板。用户在资源管理器或支持文件粘贴的目标中粘贴时得到 `.html` 文件，而不是 HTML 源码文本。临时文件必须保留到剪贴板交接完成；若平台不支持文件型剪贴板，报告错误，不退化为复制源码。
- **Android 输出**：通过 Android 原生桥接创建临时 `.html` 文件，并调用系统分享面板交付该文件。
- **浏览器/PWA 输出**：下载生成的 `.html` 文件。
- **反馈与并发**：每个导出动作在生成或平台交接期间显示忙碌且不可重复触发。成功后提示实际交付方式；失败只显示可操作的错误提示，且不影响文件预览、文件右键、回复复制或回复截图。

## 架构

前端提供一个与 PNG 截图导出并列的 HTML 导出服务：它接收 Markdown、来源路径和导出元数据，安全渲染为独立文档，并报告未能内嵌的资源。文件预览与 `prompt_done` 入口只负责收集对应内容、管理忙碌状态和显示结果。平台输出层按运行环境分流：浏览器下载、Desktop 文件剪贴板、Android 文件分享；Desktop 和 Android 的原生桥接扩展为 HTML 文件传输，而不是把 HTML 当作剪贴板文本。

## 流程

1. 用户从 Markdown 文件的更多操作菜单、Markdown 文件链接右键菜单或 `prompt_done` 操作区发起导出。
2. 前端取得源 Markdown；文件链接入口按需读取目标文件，回复入口复用现有回复导出范围。
3. 导出服务解析 Markdown，清理原始 HTML，收集项目内与远程图片；项目内图片读取后内嵌，远程图片尽力内嵌并记录失败项。
4. 服务生成含内嵌样式和内容的完整 HTML `Blob`，并交给平台输出层。
5. Desktop 通过原生桥接把临时 HTML 文件复制到系统剪贴板；Android 通过原生桥接打开文件分享；浏览器触发下载。
6. UI 清除忙碌状态，并报告成功、未内嵌资源警告或失败原因。

## 验收标准

- 预览工作台仅在活动文件为 Markdown 时显示“Export as HTML”，并能导出内容与当前 Markdown 预览一致的独立网页。
- 聊天中的 Markdown 文件链接右键菜单提供相同导出能力；非 Markdown 链接不显示该操作。
- 每个可导出的 `prompt_done` 回复提供 HTML 导出，且内容范围与既有复制和截图动作一致。
- 导出文件脱离 WheelMaker 后仍能显示文本、表格、任务列表、代码块和代码高亮，并能按系统浅/深色模式切换；核心页面渲染不加载外部 CSS 或脚本。
- 项目内相对图片会以内嵌数据展示；路径越出项目根目录的图片不会被读取。
- 可获取的远程图片被内嵌；无法内嵌时网页保留原 URL，且用户收到资源未完全内嵌的提示。
- 原始 Markdown HTML 的安全排版标签可以显示；脚本、事件属性和危险 URL 不会出现在可执行输出中。
- Desktop 导出后，粘贴到文件系统得到命名正确的 `.html` 文件，不会粘贴为源代码文本。
- Android 导出后打开系统分享面板，并以命名正确的 `.html` 文件作为分享内容。
- 浏览器/PWA 导出后下载命名正确的 `.html` 文件。
- 输出忙碌时不能重复导出；任一读取、渲染、原生交接或分享失败都会显示错误，并保持现有预览、右键、复制和截图可用。

### 测试

- 为 HTML 文档生成、文件名、Markdown 渲染资源内嵌、远程图片降级、路径边界和 HTML 清理添加单元测试。
- 为平台输出层添加 Desktop 文件剪贴板、Android 文件分享和浏览器下载的分流与失败测试。
- 为文件预览菜单、聊天文件链接右键菜单和 `prompt_done` 操作区添加 UI 测试，覆盖 Markdown 条件显示、忙碌态、成功和失败反馈。
- 不在自动化测试中验证真实操作系统剪贴板或真实 Android 分享 UI；改以原生桥接契约和调用参数验证。

## 范围之外

- 不导出非 Markdown 文件，也不将普通聊天消息、思考内容或 diff artifact 导出为 HTML。
- 不提供 HTML 模板、主题、文件名规则的设置界面，也不提供导出后在线编辑。
- 不承诺所有跨域或需鉴权的远程图片都能内嵌。
- 不改变现有 PNG 截图、回复复制、文件预览或 Desktop 文件打开行为。
