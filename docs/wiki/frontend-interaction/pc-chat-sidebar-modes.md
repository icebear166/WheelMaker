> 摘要：本页维护 PC 端 Chat 侧边栏的浮动/pin 双模式、两条常驻标题栏、滑出会话导航和 800px 对话列连续对齐规则。

# PC Chat 侧边栏模式

PC 端（宽屏 ≥900px）Chat 有浮动与 pin 两种模式，浮动态是默认值；pin 状态持久化，用户手动 pin 后跨会话记住。移动端（<900px）不参与本页规则。

## 两条常驻标题栏

- **顶部标题栏**只保留设置按钮与 hubs 下拉，搜索/archive 不在其中。它在浮动与 pin 两态都常驻、与会话列表状态无关：作为浮动元素固定在 desktop shell 左上角（不占布局宽度），会话面板（滑出层或 pin 侧边栏）从其下方开始。它渲染在 shell 层（`desktopTopBar`），不属于浮动面板堆栈。
- **全局会话标题栏**是会话面板（滑出层与 pin 侧边栏共用）的真正标题栏，不显示「Recent Sessions」字样，且在面板内置顶、不随列表滚动。按钮矩阵：浮动态 recent 面板 `[全部session/收起] [pin]` 居左；滑出层与 pin 侧边栏 `[pin]` 居左、`[搜索] [archive]` 居右。组件接口与端无关，为移动端后续复用预留。

## 浮动态滑出会话导航

- 点「全部session」滑出完整会话导航，滑出面板与 pin 态会话面板完全同构：全局会话标题栏置顶 + 完整会话导航（项目分组 + older folding + archive 入口，含 recent 分组），宽度固定 360px 不可调，从左侧动画滑入/滑出，层叠在 plan/Limits 面板与文字区之上。pin 只是把同一面板变为不可收回的固定布局。
- 面板常挂载，scrollTop 天然保留；鼠标移出自动滑回，但搜索框聚焦、菜单打开、拖拽滚动条期间抑制滑回。

## pin 模式

pin 态把同构会话面板固定进左侧布局：全局会话标题栏置顶于侧边栏（不随 `.sidebar-scroll` 滚动），下方为完整会话导航；recent 分组不显示分组头部。plan 面板在会话列表右侧的既有位置，recent 浮动面板不显示。

## 800px 对话列连续对齐

800px 视图模式下文字列宽度恒定不缩窄。主窗口 W = 窗口宽 − preview 宽 − pin 侧边栏宽（浮动态为 0），R 为悬浮列预留宽（浮动列宽 + edge-gap）。文字列左 margin 随 W 连续分段变化、无跳变：

1. **居中段**：左 margin = (W − 800) / 2；
2. **左贴段**：居中会侵入 R 时，左 margin 保持 R，右 gutter 继续收缩；
3. **遮挡段**：右 gutter 收至最小值后，左 margin 侵入 R，文字列经 fade mask 遮挡悬浮列。

pin 态与浮动态共用同一公式。
