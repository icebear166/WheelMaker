> 摘要：本页维护 PC 端 Chat 侧边栏的浮动/pin 双模式、两条常驻标题栏、滑出会话导航和 800px 对话列连续对齐规则。

# PC Chat 侧边栏模式

PC 端（宽屏 ≥900px）Chat 有浮动与 pin 两种模式，浮动态是默认值；pin 状态持久化，用户手动 pin 后跨会话记住。移动端（<900px）不参与本页规则。

## 两条常驻标题栏

- **顶部标题栏**只保留设置按钮与 hubs 下拉，搜索/archive 不在其中。它在浮动与 pin 两态都常驻；浮动态下它是浮动元素，浮在聊天区左上角、recent 面板上方，不占布局宽度，聊天区通栏。
- **全局会话标题栏**是 recent 面板标题栏的迭代形态，用于浮动态 recent 面板与 pin 态侧边栏 recent 区。按钮矩阵：浮动态 `[全部session/收起] [pin]` 居左、滑出后 `[搜索] [archive]` 居右；pin 态 `[pin] [搜索] [archive]`。组件接口与端无关，为移动端后续复用预留。

## 浮动态滑出会话导航

- 点「全部session」从 recent 面板原位滑出完整会话导航（项目分组 + older folding + archive 入口，与 pin 态导航同源），宽度等于浮动列宽（`--chat-edge-surface-width`，360px），层叠在 plan/Limits 面板与文字区之上；标题栏与 recent 共用并 sticky 置顶。
- 打开时恢复上次滑出的 scrollTop；鼠标移出自动滑回，但搜索框聚焦、菜单打开、拖拽滚动条期间抑制滑回。

## pin 模式

pin 态保持固定侧边栏行为：会话导航固定左侧，plan 面板在会话列表右侧的既有位置，recent 浮动面板不显示。

## 800px 对话列连续对齐

800px 视图模式下文字列宽度恒定不缩窄。主窗口 W = 窗口宽 − preview 宽 − pin 侧边栏宽（浮动态为 0），R 为悬浮列预留宽（浮动列宽 + edge-gap）。文字列左 margin 随 W 连续分段变化、无跳变：

1. **居中段**：左 margin = (W − 800) / 2；
2. **左贴段**：居中会侵入 R 时，左 margin 保持 R，右 gutter 继续收缩；
3. **遮挡段**：右 gutter 收至最小值后，左 margin 侵入 R，文字列经 fade mask 遮挡悬浮列。

pin 态与浮动态共用同一公式。
