> 摘要：本页说明 WheelMaker 文档目录的分区、用途和维护入口。

# WheelMaker Documentation

## 长期知识

- [`wiki/`](wiki/wiki.md)：当前、稳定、跨任务仍然有效的项目知识。
- [`references/`](references/README.md)：完整保留的版本化、历史性或稳定与草案混合的来源文档。

## 工作产物

- [`adr/`](adr/)：已确认的架构决策记录。
- [`scope/`](scope/)：按需求组织的规格与实施计划。
- [`plans/`](plans/)：没有独立 scope 的实施计划。
- [`reviews/`](reviews/)：架构审查、代码审计和其他评审产物。
- [`handoff/`](handoff/)：供后续工作接续的阶段性交接材料。
- [`superpowers/`](superpowers/)：早期工作流留下的规格与计划，作为历史记录保留。

## 资源

- [`readme-assets/`](readme-assets/)：README 和安装文档使用的图示资源。

## 维护原则

- 当前事实、长期约定和稳定流程进入 wiki。
- 外部协议全文、版本化快照、历史说明或混合了草案的材料放入 references。
- 未确认方案、一次性计划、评审结论和会话流水保留在对应工作产物目录，不作为当前事实写入 wiki。
- 移动权威页面时同步更新运行时指导、测试夹具和有效文档链接；历史计划中的原始路径可以作为当时记录保留。
